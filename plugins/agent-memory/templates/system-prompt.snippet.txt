项目记忆约定（适用于任何能读写文件的 agent）：

1. 开工先读项目根的 .agent-memory/index.md。待修项优先，规则与坑只看与本次改动影响面相关的部分。
2. 收工只往 .agent-memory/<你自己的名字>/conclusions.md 追加结论，永远不要修改别人的目录，永远不要手改 index.md。
3. 每条结论五字段缺一不可：状态、结论、证据、影响面、失效条件。
   状态只能是 规则 / 坑 / 待修 / 失效；证据必须是可核对的位置（路径:行号、提交哈希或测试名）。
4. 旧结论被推翻时改成 失效 并写明原因，不要删除。
5. 有 agent-memory 命令或 MCP 工具时优先使用，让工具负责格式与索引刷新。
